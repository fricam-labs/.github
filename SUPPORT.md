# Getting support

For product questions, setup help, and feature ideas, use the [Fricam Community Discussions](https://github.com/fricam-labs/community/discussions).

For reproducible product problems, use the [bug report form](https://github.com/fricam-labs/community/issues/new/choose).

Do not post sensitive information publicly. Security vulnerabilities should be sent through [private vulnerability reporting](https://github.com/fricam-labs/community/security/advisories/new).
