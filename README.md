# Fricam Labs

Fricam builds native, private companions for self-hosted [Frigate](https://frigate.video/) camera systems.

Your cameras and server remain yours. Fricam connects to the Frigate server you choose, helping you check live views, events, alerts, and recordings without relying on a shared cloud camera service.

## Community

Questions, feature ideas, product feedback, and reproducible bug reports belong in our [Community repository](https://github.com/fricam-labs/community). The mobile application source code is private.

- [Ask a question or get help](https://github.com/fricam-labs/community/discussions)
- [Share a product idea](https://github.com/fricam-labs/community/discussions/categories/ideas)
- [Report a reproducible bug](https://github.com/fricam-labs/community/issues/new/choose)
- [Report a security vulnerability privately](https://github.com/fricam-labs/community/security/advisories/new)

Fricam is independent software and is not affiliated with the Frigate project.
